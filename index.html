Task 1 (Option B) 12 Points

Turn-Based Battle Game

Hero and enemy turn-based combat with 100 HP, dynamic attack ranges (8–15 and 5–14), 10% critical hits, defense reduction, and heal limit.

  • Constants stored at top of script (HP, ranges, crit rate)
  • Fair random RNG with Math.floor(Math.random() * (max - min + 1)) + min
  • 3+ game outcomes decided with &&, ||, ===
  • Invalid moves rejected without changing game state
  • Restarts dynamically in-place without page reloading

Kanban Board from Data

Fully dynamic 3-column project board rendered from an array of 12 objects using createElement with zero innerHTML for data.

  • 12 task objects with 6 diverse properties (number, string, bool)
  • HTML has only empty containers
  • Single render() function updates board on every change
  • Rule-blocked action: In Progress holds max 3 cards (WIP limit)
  • Custom for...of loop computes progress % & delivered points
