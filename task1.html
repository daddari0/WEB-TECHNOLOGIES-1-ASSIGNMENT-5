Task 1 Verification & Technical Requirements
1. Stored Constants at Top of Script: HERO_MAX_HP = 100, ENEMY_MAX_HP = 100, HERO_ATTACK_MIN = 8, HERO_ATTACK_MAX = 15, ENEMY_ATTACK_MIN = 5, ENEMY_ATTACK_MAX = 14, HEAL_AMOUNT = 20, MAX_HEALS = 3, CRIT_CHANCE = 0.10.
2. Three Outcomes with &&, ||, ===: Victory (enemyHp <= 0 && heroHp > 0), Defeat (heroHp <= 0 && enemyHp > 0), Mutual K.O. (heroHp <= 0 && enemyHp <= 0). Invalid heal check uses remainingHeals <= 0 || heroHp === HERO_MAX_HP.
3. Fair Random Generator: Math.floor(Math.random() * (max - min + 1)) + min guarantees equal probability for both the lowest and highest boundaries.
4. State Retention & In-Place Restart: Invalid moves produce an in-page alert without state mutations. The Restart button re-initializes all state variables and DOM nodes without browser reload.
