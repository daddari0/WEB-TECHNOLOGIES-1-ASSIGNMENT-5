Task 2 Technical Requirements Verification
1. Data Model (12 Objects, Multiple Types): Every card item features id (number), title (string), priority (string), tag (string), storyPoints (number), status (string), and isFlagged (boolean).
2. Zero innerHTML for Data (Strict Compliance): All cards and empty-state placeholders are constructed strictly with document.createElement(), textContent, classList, and dataset.
3. Rule-Blocked Action (WIP Limit): The middle column ("In Progress") enforces a strict limit of 3 cards max. Attempting to move a 4th card is intercepted, blocked, and displays a warning banner without mutating the array.
4. Custom Loop & Event Delegation: Progress % and completed story points are computed via a dedicated for...of loop. Card action buttons are managed by a single event listener on #kanbanBoard via event.target.closest('button[data-action]').
